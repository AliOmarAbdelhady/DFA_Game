How to Play

1

Build a State Machine

Click on the canvas to add states. Each state is a circle representing a position in your automaton.

2

Set Start & Accept States

Select a state and click "Set Start" to mark where your machine begins. Toggle "Accept" for states that open the door.

3

Add Transitions

Right-click a state to add transitions. Each symbol must have exactly one transition from each state.

4

Test Your Solution

Click "Unlock Door" to test your automaton against all keys. Get 3 stars for perfect solutions!
