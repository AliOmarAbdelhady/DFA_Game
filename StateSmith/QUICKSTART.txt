🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: Can't start the server
Solution: 
   • Check Python is installed
   • Ensure all dependencies installed
   • Try: pip install -r requirements.txt

Problem: Can't log in
Solution:
   • Create account first (Sign Up tab)
   • Check username/email and password
   • Clear browser cookies

Problem: Progress not saving
Solution:
   • Ensure you're logged in (see username in menu)
   • Check for error messages in console (F12)
   • Verify statesmith.db file exists

Problem: Database errors
Solution:
   • Delete statesmith.db file
   • Restart application
   • Database will be recreated

Problem: Port 5001 already in use
Solution:
   • Change port in app.py (last line)
   • Or stop other service using port 5001
